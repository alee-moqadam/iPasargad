پرداخت مستقیم

پرداخت مستقیم به شما این امکان را می‌دهد که از حساب دیجیتال خود برای سرمایه‌گذاری در صندوق‌های سرمایه‌گذاری استفاده نمایید.

ویپاد

ویپاد یک بانک دیجیتال است که با تکنولوژی‌های نوین، تمامی خدمات بانکی ضروری را از طریق اپلیکیشن خود به‌صورت تجربه‌ای جدید برای شما فراهم می‌کند. ویپاد با حمایت بانک پاسارگاد و پشتیبانی بانک مرکزی ایران، از اواخر سال ۱۳۹۸ فعالیت خود را آغاز کرده و تمام سپرده‌های کاربران آن نزد بانک پاسارگاد نگهداری می‌شود.

دسترسی به حساب دیجیتال ویپاد منقضی شده است. برای استفاده از خدمات پرداخت مستقیم، لطفاً دسترسی را به‌روزرسانی کنید.
