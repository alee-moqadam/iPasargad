# چک‌لیست آدیت UI/UX آی‌پاسارگاد

## اصل‌های پایه

- [ ] آیا مسیرهای آشنای کاربران فعلی حفظ شده‌اند؟
- [ ] آیا تغییرات فقط در لایه نمایش هستند؟
- [ ] آیا طراحی موبایل‌محور بررسی شده است؟
- [ ] آیا ویو اول هر صفحه هدف صفحه را واضح نشان می‌دهد؟
- [ ] آیا عملیات اصلی قابل لمس و واضح هستند؟

---

## داشبورد

- [ ] ارزش کل دارایی در ویو اول مشخص است.
- [ ] وضعیت فوری یا درخواست مهم در صورت وجود دیده می‌شود.
- [ ] سرمایه‌گذاری، برداشت و تبدیل قابل دسترس هستند.
- [ ] چهار صندوق اصلی خلاصه و قابل اسکن هستند.
- [ ] خدمات جانبی پایین‌تر از عملیات اصلی قرار گرفته‌اند.
- [ ] داشبورد جای پرتفوی یا گزارش‌ها را نگرفته است.

---

## صندوق‌ها

- [ ] کارت صندوق‌ها در موبایل خواناست.
- [ ] هر صندوق هدف یا مناسب‌بودن مشخص دارد.
- [ ] بازده بدون ریسک نمایش داده نشده است.
- [ ] سرمایه‌گذاری و جزئیات واضح هستند.
- [ ] وضعیت دارایی کاربر در صندوق در صورت وجود مشخص است.

---

## دارایی / پرتفوی

- [ ] کاربر می‌فهمد پولش کجاست.
- [ ] هر دارایی به شکل کارت مستقل نمایش داده شده است.
- [ ] عملیات سرمایه‌گذاری بیشتر، برداشت و تبدیل واضح هستند.
- [ ] صفحه تکرار کامل داشبورد نیست.
- [ ] حالت خالی راهنما و اقدام دارد.

---

## گزارش‌ها

- [ ] وضعیت هر درخواست قابل فهم است.
- [ ] فیلترها در موبایل قابل لمس هستند.
- [ ] هر آیتم گزارش قابل اسکن است.
- [ ] دسترسی به جزئیات یا رسید حفظ شده است.

---

## موبایل

- [ ] عرض کارت‌ها مناسب موبایل است.
- [ ] دکمه‌ها اندازه لمسی مناسب دارند.
- [ ] متن‌ها بیش از حد طولانی نیستند.
- [ ] محتوای مهم زیر انبوه کارت‌های جانبی دفن نشده است.
- [ ] نوار پایین قابل فهم و آشناست.
