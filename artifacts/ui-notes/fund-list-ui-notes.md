# یادداشت UI صفحه صندوق‌ها

## وضعیت

صفحه صندوق‌ها به‌عنوان اولین صفحه UI-only بازطراحی شد.

## هدف تغییر

هدف این تغییر، تبدیل صفحه صندوق‌ها به یک صفحه موبایل‌محور، کارت‌محور و قابل اسکن بود؛ بدون تغییر در سرویس‌ها، API، مسیرهای اصلی یا منطق واقعی کسب‌وکار.

## اصول رعایت‌شده

- حفظ مسیرهای آشنای کاربر
- حفظ کامپوننت عملیاتی قبلی `app-fund-item`
- استفاده از دامی‌دیتای کامپوننتی فقط برای پیش‌نمایش UI
- عدم تغییر در سرویس‌ها و اتصال‌های واقعی
- تمرکز روی چهار صندوق اصلی آی‌پاسارگاد
- نمایش ریسک، بازده منتخب، نقدشوندگی و وضعیت دارایی کاربر

## چهار صندوق اصلی

- هزاره سوم: صندوق درآمد ثابت صدور و ابطالی هزاره سوم پاد
- پاسارگاد: صندوق درآمد ثابت قابل معامله پاسارگاد
- ریتون: صندوق طلای قابل معامله چندکالایی پاسارگاد
- تکپاد: صندوق سهامی قابل معامله ارزش پرداز آریان

## نکات قابل بررسی در ادامه

- بررسی نمایش کارت‌ها در موبایل واقعی
- بررسی اینکه دکمه‌های داخل `app-fund-item` از نظر ظاهری با کارت جدید هماهنگ هستند یا نه
- بررسی نیاز به کوچک‌سازی متن‌های کارت
- تصمیم‌گیری درباره نمایش یا حذف گزینه «مقایسه سبک صندوق‌ها»
- تصمیم‌گیری درباره فعال بودن `useMockViewData` قبل از تحویل نهایی
