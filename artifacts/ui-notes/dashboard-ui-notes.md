# یادداشت UI داشبورد

## وضعیت

داشبورد به‌عنوان دومین صفحه اصلی UI-only وارد فاز بازطراحی شد.

## هدف تغییر

هدف، تبدیل داشبورد به مرکز کنترل سریع و موبایل‌محور کاربر است؛ بدون تغییر در سرویس‌ها، API، احراز هویت، پرداخت، سجام یا منطق واقعی کسب‌وکار.

## ساختار پیشنهادی داشبورد

- معرفی کوتاه صفحه و وضعیت پروفایل
- خلاصه ارزش کل دارایی
- وضعیت درخواست‌های در جریان
- عملیات اصلی: سرمایه‌گذاری، برداشت، تبدیل صندوق
- راهنمای کوتاه سرمایه‌گذاری و تبدیل
- نمای کلی چهار صندوق اصلی
- روند دارایی
- فعالیت‌های اخیر
- سرویس‌های کاربردی در سطح پایین‌تر
- راهنمای مشاوره

## اصول رعایت‌شده

- حفظ مسیرهای آشنای کاربر
- حفظ عملیات اصلی در ویو اول
- پایین‌بردن سرویس‌های جانبی نسبت به عملیات اصلی
- استفاده از دامی‌دیتای کامپوننتی فقط برای پیش‌نمایش UI
- عدم تغییر در سرویس‌ها و اتصال‌های واقعی
- موبایل‌محور بودن سلسله‌مراتب محتوا

## چهار صندوق اصلی در داشبورد

- هزاره سوم: صندوق درآمد ثابت صدور و ابطالی هزاره سوم پاد
- پاسارگاد: صندوق درآمد ثابت قابل معامله پاسارگاد
- ریتون: صندوق طلای قابل معامله چندکالایی پاسارگاد
- تکپاد: صندوق سهامی قابل معامله ارزش پرداز آریان

## نکات قابل بررسی در ادامه

- بررسی ارتفاع ویو اول در موبایل واقعی
- بررسی تراکم کارت خلاصه دارایی و عملیات اصلی
- بررسی هماهنگی ظاهری کارت‌های صندوق با صفحه صندوق‌ها
- بررسی نیاز به حذف یا کم‌رنگ‌کردن بخش‌های تکراری مثل فعالیت mock و کامپوننت واقعی فعالیت‌ها
- تصمیم‌گیری درباره فعال بودن `useMockViewData` قبل از تحویل نهایی
