# سیاست تغییرات لایه نمایش

## اصل اصلی

در فاز فعلی، تغییرات فقط باید در محدوده رابط کاربری، تجربه کاربری و لایه نمایش انجام شوند.

این پروژه موبایل‌محور است؛ بنابراین هر تغییر نمایشی باید ابتدا در اندازه و رفتار موبایل بررسی شود.

---

## فایل‌های مجاز برای تغییر

- فایل‌های HTML کامپوننت‌ها
- فایل‌های SCSS / CSS کامپوننت‌ها
- فایل TypeScript کامپوننت فقط برای منطق نمایشی
- دامی‌دیتای محلی داخل کامپوننت برای پیش‌نمایش UI

---

## فایل‌هایی که نباید تغییر کنند

- سرویس‌های واقعی
- REST services
- Interceptors
- Guards
- Auth logic
- Payment logic
- Sejam logic
- Token/session logic
- Environment files
- Route structure
- Shared domain models
