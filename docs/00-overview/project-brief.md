# خلاصه پروژه آی‌پاسارگاد

## هدف این مستند

این مستند مبنای کاری پروژه آی‌پاسارگاد است و برای هماهنگ‌کردن تصمیم‌های طراحی، ساختاردهی، مستندسازی و بهبود لایه نمایش استفاده می‌شود.

## وضعیت پروژه

آی‌پاسارگاد یک پروژه انگولار چندبخشی است که شامل دو اپلیکیشن اصلی است:

- `client`: اپ اصلی کاربر
- `landing`: لندینگ و صفحات معرفی/بازاریابی

## اصل کلیدی پروژه

اپ آی‌پاسارگاد در حال حاضر توسط کاربران واقعی استفاده می‌شود. بنابراین هر نوع بهبود طراحی، رابط کاربری و تجربه کاربری باید محافظه‌کارانه، تدریجی و بدون شکستن مسیرهای آشنای کاربر انجام شود.

## محدوده فعلی کار

در این فاز فقط روی موارد زیر کار می‌کنیم:

- ساختاردهی مستندات پروژه
- تحلیل فلوهای موجود
- بازتعریف نقش صفحات و منوهای اصلی
- بهبود لایه نمایش
- اصلاح اچ‌تی‌ام‌ال، اس‌سی‌اس‌اس و منطق نمایشی کامپوننت‌ها
- استفاده از دامی‌دیتای کامپوننتی برای پیش‌نمایش ویوها در حالت لوکال

## خارج از محدوده فعلی

در این فاز به موارد زیر دست نمی‌زنیم:

- سرویس‌های واقعی
- اتصال‌های API
- احراز هویت
- پرداخت
- سجام
- اینترسپتورها
- روت‌گاردها
- منطق ذخیره توکن
- مدل‌های اصلی دامنه
- مسیرهای اصلی کاربر مگر در حد مستندسازی و تحلیل

## هدف تجربه کاربری

هدف این نیست که اپ از نو طراحی شود. هدف این است که همان تجربه آشنا برای کاربران فعلی، خواناتر، مرتب‌تر، قابل فهم‌تر و کاربردی‌تر شود.
